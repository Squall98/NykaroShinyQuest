Concept : tes chances de shiny démarrent à 0 et montent à chaque palier de quêtes complété, de 2% jusqu'à 100%.

Choix d'architecture

  • Sans mixin — toute la progression passe par les événements publics de Cobblemon (capture, combat, évolution, niveau, spawn). Plus propre et plus robuste aux mises à jour.
  • Pont isolé — un seul fichier (CobblemonBridge.java) touche à l'API Cobblemon. Tout le reste compile indépendamment.
  • Progression = agrégats — on stocke des compteurs simples (captures, défaites, types, niveau max…) ; les quêtes se calculent à la volée. Sauvegarde légère.
  • Sync réseau JSON — le serveur envoie un instantané compact au client pour le HUD et le GUI.

Prompts IA pour les visuels

Génère ces images, envoie-les moi, je les intègre. Format PNG, fond transparent recommandé (sauf l'icône).

1 · Icône du mod (128×128, carré)

A polished game mod icon, 128x128, square. A glowing sparkle/shiny star
symbol (Pokemon shiny style, four-point sparkle) in cyan and white,
centered over a deep purple-to-navy night gradient background. Subtle
magic glow, clean vector-like shading, high contrast, no text.
Crisp edges, app-icon quality.

2 · Fond du menu des quêtes (256×200, GUI)

A Minecraft-style GUI panel background, flat and clean, 256x200.
Dark violet parchment / arcane tablet look with a thin glowing cyan
border, faint sparkle motifs in the corners. Pixel-art friendly,
readable behind text, no words, subtle so text stays legible.

3 · Badges de palier (32×32, ×6)

A set of 6 small circular tier badges, 32x32 each, pixel-art style,
matching a Pokemon shiny theme. Progressive rarity: bronze, silver,
gold, emerald, sapphire, prismatic rainbow. Each with a small sparkle,
clean outline, transparent background, no text.

4 · Icône HUD étincelle (16×16)

A tiny 16x16 pixel-art shiny sparkle icon, cyan/white four-point star,
transparent background, crisp Minecraft HUD style.

Dis-moi le style que tu préfères (pixel-art strict vs semi-réaliste) et j'ajuste les prompts. Une fois les images prêtes, je les place dans assets/nykaroshiny/textures/ et je branche le GUI dessus.

Mise en ligne GitHub

Le dépôt est déjà initialisé en local (git) avec commits propres. Étapes pour publier :

  • Me donner ton pseudo GitHub → je remplace NYKARO_GITHUB dans les fichiers.
  • Créer le repo public nykaros-shiny-quest (je peux le faire via gh).
  • git push vers GitHub.
  • Pour une release : pousser un tag v1.0.0 → la CI compile et publie le jar automatiquement.

CI déjà configurée

.github/workflows/build.yml : build à chaque push, et création automatique d'une release GitHub (avec le .jar) quand un tag v* est poussé.

NykaroShinyQuest

Un mod Minecraft (Cobblemon) : tes chances de shiny augmentent au fil des quêtes.

Pour qui ?

Les joueurs de Cobblemon qui trouvent la chasse aux shiny trop aléatoire et veulent une progression qui récompense le jeu.

✓

6 paliers de quêtes : capturer, combattre, faire évoluer, monter en niveau…

✓

Des chances de shiny qui montent de 2 % jusqu'à 100 % (réglable).

✓

Interface des quêtes, affichage des chances en jeu, son et particules à chaque quête.

✓

Progression par joueur ou pour tout le serveur, en français et en anglais.

Comment ça marche

Mod Fabric pour Minecraft 1.21.1 qui s'appuie sur Cobblemon 1.6+. La configuration est un fichier JSON créé au premier lancement.
  1. Installer Fabric pour Minecraft 1.21.1.
  2. Mettre dans mods/ : Fabric API, Fabric Language Kotlin, Cobblemon et le .jar du mod (page Releases du dépôt).
  3. En jeu : touche G pour les quêtes, /shinyquest pour les commandes.

À savoir

  • Minecraft 1.21.1 et Cobblemon 1.6+ seulement.

🎯 Le concept

Au début, tes chances de shiny sont normales. En accomplissant des quêtes

(capturer, combattre, faire évoluer, monter en niveau…), tu débloques des

paliers qui augmentent tes chances de shiny — jusqu'à 100 % pour les

dresseurs les plus accomplis.

PalierNomChances de shiny
1Premiers pas2 %
2Apprenti Dresseur5 %
3Chasseur aguerri10 %
4Expert Cobblemon25 %
5Maître de la Chasse50 %
6Légende Chromatique100 %

*(Valeurs entièrement configurables.)*

✨ Fonctionnalités

  • 📜 Quêtes progressives réparties en 6 paliers.
  • 👤 Progression par joueur (ou globale au serveur, au choix).
  • ⚙️ Configuration JSON : courbe de chances, objectifs, options.
  • 🖥️ Interface graphique des quêtes (raccourci clavier).
  • 📊 HUD affichant tes chances de shiny en jeu.
  • 🔊 Feedback : son + particules à chaque quête terminée.
  • 💬 Commandes : /shinyquest odds | progress | set | reset.
  • 🌍 Traductions français et anglais.

    • 📦 Prérequis

  • Minecraft 1.21.1
  • Fabric Loader 0.16.9+
  • Fabric API
  • Cobblemon 1.6+
  • Fabric Language Kotlin *(requis par Cobblemon)*

    • 🚀 Installation

  • Installe Fabric pour Minecraft 1.21.1.
  • Place dans ton dossier mods/ : Fabric API, Fabric Language Kotlin, Cobblemon,

    • et nykaros-shiny-quest-x.y.z.jar.

  • Lance le jeu, ouvre le menu des quêtes avec le raccourci (par défaut G).

    • ⚙️ Configuration

    Le fichier config/nykaroshiny.json est généré au premier lancement.

    Tu peux y régler la courbe de chances, les objectifs des quêtes, la

    progression par joueur, l'affichage du HUD et le feedback.

    🛠️ Compilation depuis les sources

    git clone https://github.com/NYKARO_GITHUB/nykaros-shiny-quest.git
cd nykaros-shiny-quest
./gradlew build

    Le jar final se trouve dans build/libs/.
